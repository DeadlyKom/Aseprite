# Плагины Aseprite

Два самостоятельных Lua-инструмента для Aseprite. Можно установить любой из них или оба. Совместная работа двух режимов на одном документе отдельно не проверена.

## Что выбрать

| Плагин | Для чего нужен | Файл для установки | Инструкция по работе |
| --- | --- | --- | --- |
| **Spectrum Screen** | Рисование ZX Spectrum на штатном холсте: INK/PAPER/BRIGHT, клетки 8×8, поиск и исправление ошибок, импорт/экспорт SCR | [spectrum-screen.lua](spectrum-screen/outputs/spectrum-screen.lua) | [Инструкция Spectrum Screen](spectrum-screen/README.md) |
| **Hex Repeat** | Рисование по собственной пиксельной маске гексагона с шестью повторами на основном холсте и его автоматическим расширением | [hex-repeat.lua](hex-repeat/outputs/hex-repeat.lua) | [Инструкция Hex Repeat](hex-repeat/README.md) |

Для каждого плагина нужен **один Lua-файл**. Устанавливать целиком папку проекта, документацию или содержимое `work/` не нужно. Требования к рисунку и ограничения приведены в инструкции выбранного плагина. Проверки выполнялись на Aseprite **1.3.18.6 / API 41**.

## Установка

1. В Aseprite откройте **File → Scripts → Open Scripts Folder**.
2. Скопируйте в открывшуюся папку выбранный `.lua` из таблицы выше.
3. Выполните **File → Scripts → Rescan Scripts Folder (F5)**.
4. Запустите **File → Scripts → spectrum-screen** или **hex-repeat**.
5. Подготовьте рисунок и включите режим по инструкции соответствующего плагина.

В обычной установке Windows папка скриптов находится в `%APPDATA%\Aseprite\scripts`. В portable-установке используйте папку, которую открыл сам редактор. Компиляция и сборка не требуются.

## Обновление

1. Закройте панель обновляемого плагина.
2. Замените его Lua-файл в папке Scripts актуальным файлом из репозитория.
3. Обновите список через **F5** и снова запустите скрипт.

Изменения в репозитории не обновляют установленную копию автоматически.

Если остались старые вспомогательные файлы Spectrum — `spectrum-zx-ink.lua`, `spectrum-zx-paper.lua`, `spectrum-zx-bright.lua` или `spectrum-zx-pick.lua` — удалите их из Scripts. Текущая версия использует только `spectrum-screen.lua`, все переключатели находятся в его панели.

## Запуск с клавиатуры

В **Edit → Keyboard Shortcuts** найдите **File → Scripts → spectrum-screen** или **hex-repeat** и назначьте удобное сочетание для открытия панели. Автоматически горячие клавиши не назначаются.
